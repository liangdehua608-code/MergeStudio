关于

v6 把工具拆成可维护的包：队列 + 合并/裁剪 + 提取音频，全部本地运行

任务队列暂停 / 重试 优先级排序批量建任务 合并前预检片头片尾裁剪 画面裁剪 / 去台标章节标记 合并后自检提取音频 硬件编码本地运行

队列采用单 worker 串行执行：同一时刻只有一个 ffmpeg 在跑， 不会因为多任务抢占磁盘导致所有任务一起变慢。批处理多门课程时， 把任务排好队然后去睡觉就行。
